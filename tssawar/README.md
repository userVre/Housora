# Archived visuals

This directory contains screenshots, inspiration references, design concepts,
and image families that are not used by the production website.

The files are archived rather than deleted. Their original bytes and source
directory structure are preserved. Nothing under `tssawar/` is copied into the
website build or served by Ktor.

- `inspiration/`: reference-site screenshots.
- `website-screenshots-complete/`: generated website audit captures and reports.
- `design-concepts/`: generated UI concept images.
- `static-images/`: former production image families with no remaining source reference.
- `signin-after-click.png`: standalone authentication screenshot.
