# Housora production asset manifest

Generated and verified: 2026-08-13

## Result

Before this pipeline, the rendered site contained **152 unique `/static/...`
references: 4 present and 148 missing**. The root `/og-image.png` reference was
also missing. The baseline was measured from concrete `src`, `href`, `poster`,
and metadata `content` attributes in `dist/**/*.html`.

Run `bun run build` for the complete production flow. If the application server
is already running, use the static-export entrypoint directly:

```text
bun run build:static
```

`assets:build` is deterministic from pinned npm packages, the checked-in Clerk
browser distribution, and project-owned source files. `assets:verify` exits
non-zero if a concrete rendered asset is
absent or empty. The full machine-readable inventory, including every Kotlin,
CSS, JavaScript, and rendered HTML origin, is
`static/assets/asset-report.json`.

## Sources and licensing assumptions

| Asset set | Source | Assumption |
|---|---|---|
| Existing CSS and JavaScript | Existing tracked `static/css` and `static/js` | Project-owned application code |
| Clerk browser SDK | Checked-in upstream `@clerk/clerk-js@6.25.7` browser distribution | MIT; upstream license retained at `static/vendor/clerk-js/LICENSE.txt` |
| Clerk UI compatibility path | Generated 68-byte no-op shim | Clerk 6.25.7 already bundles its UI in `clerk.browser.js`; the shim satisfies the historical layout path without executing the SDK twice |
| PostHog browser SDK | `posthog-js@1.417.1`, upstream `dist/array.js` | Apache-2.0 AND MIT; upstream license copied to `static/vendor/posthog/LICENSE.txt` |
| Convex browser client | `convex@1.44.0`, upstream `dist/browser.bundle.js` | Apache-2.0; upstream license retained at `static/vendor/convex/LICENSE.txt` |
| Favicon, app icons, social preview | Geometric Housora mark generated by `scripts/build-assets.js` | Original project branding; depicts no property, person, product, or testimonial |
| Product/content images | Neutral generated placeholders | No third-party imagery or factual claims; every placeholder is visibly labeled “Visual pending” |

Reference screenshots, visual concepts, and unused image families are archived
under `tssawar/`. They are not part of the production website and are never
copied to `dist/`. Their image rights and suitability as standalone Housora
content assets are not established. The similarly named Convex skill icons are
unrelated tooling assets and were not reused.

## Pinned browser bundles

The generator validates the checked-in Clerk entrypoint and its same-version
dynamic browser chunks. It copies PostHog's smallest classic-script build compatible
with the existing `window.posthog` integration, rather than its full bundle.
Source maps are not shipped. Version checks in `scripts/build-assets.js`
validate vendored Clerk 6.25.7 and fail if installed PostHog drifts from 1.417.1
or Convex drifts from 1.44.0.

Playwright is development-only because it serves audit/capture scripts. Sharp
0.35.3 is development-only and is required to create production images; neither
package is included in a browser bundle.

## Images and responsive behavior

The generator currently manages **160 image fallbacks** referenced by active or
potential Kotlin/CSS/JavaScript paths. Each missing source receives a deliberate
neutral JPEG with the aspect ratio intended by that placement. It also emits
**960 responsive AVIF/WebP variants** at sensible intrinsic breakpoints (up to
320, 640, 960, and the source width). `static/js/main.js` progressively wraps
eligible images in `<picture>` elements using
`static/assets/responsive-images.json`; JPEG remains the universal fallback.
Existing width/height attributes and meaningful alt text are retained, and
generated placeholders are marked at runtime with
`data-neutral-placeholder="true"`.

Metadata assets generated under `static/meta/` and published at the site root:

- `favicon.ico` (32×32 ICO containing PNG data)
- `favicon.svg`
- `apple-touch-icon.png` (180×180)
- `icon-192.png`
- `icon-512.png`
- `site.webmanifest`
- `og-image.png` (1200×630 social fallback)
- `og-image.webp` and `og-image.avif` (optimized optional variants)
