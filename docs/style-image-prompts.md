# Housora examples — 30 style image prompt pack

Generate five landscape images for every style in this order: **living room, kitchen, bedroom, bathroom, dining room**. Keep the camera height, realism, and finish quality consistent inside each five-image set.

## Add this quality suffix to every prompt

`Photorealistic editorial interior photograph, physically believable materials and construction, natural daylight plus subtle practical lighting, clean architectural composition, 3:2 landscape, no people, no pets, no text, no logos, no watermark, no collage, no distorted furniture, no fisheye lens.`
